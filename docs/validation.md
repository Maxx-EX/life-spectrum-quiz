## 一、本测试是什么（明确边界）

**LSM-140 是一套内容原创、结构清晰的开源自我探索工具，而非经过实证校准的标准化心理测量量表。**

它适合：自我探索、自我反思、教育科普、内容展示、入门的心理测评体验。
它**不**适合、也**不得**被当作：医疗诊断、精神健康评估、人才选拔、法律或保险等任何高利害评估的依据。

## 三、未验证项（诚实列出）

以下为心理测量学的核心实证指标，**LSM-140 目前均未建立**：

| 指标 | 当前状态 | 意义 |
|---|---|---|
| 大样本施测 | 未开展 | 无样本，无法建立分布形态 |
| 常模（Norm） | 未建立 | 无参照人群，无法给出百分位/标准分对照 |
| 内部一致性（Cronbach's α） | 未计算 | 无从判断各维度题目的同质性 |
| 重测信度（test–retest） | 未评估 | 无从判断跨时间的稳定性 |
| 效标关联效度 | 未检验 | 无从判断得分与外在校标（如成熟量表）的相关 |
| 维度结构（因子分析 EFA/CFA） | 未进行 | 14 维结构未经统计证实，目前仅为理论假定 |
| 同行评审 / 发表 | 未进行 | 未经独立专家评审 |

**因此，在心理测量学意义上，LSM-140 尚未达标为标准化测量工具；本声明即为该定位的正式记录。**

## 四、关于「认知性别四分类」的阈值说明

结果页的"认知性别画像"按**工具效能 / 表达温暖**两维在 55 分处切分，给出：

- 双性化倾向（两维均 ≥ 55）
- 工具导向倾向（仅工具 ≥ 55）
- 表达导向倾向（仅表达 ≥ 55）
- 探索型 / 待成形（两维均 < 55）

**重要声明**：该 55 分阈值为**暂定设计值**，未经常模与统计检验，仅用于呈现"取向倾向"的探索性提示，**不构成任何分类诊断**。待完成常模与信效度研究后，方可据此校准阈值或改为连续评分表述。所谓"心理双性化"概念与 Bem（1974）的双性化理论相关，但本量表的构念、题目与计分均为原创实现，不构成对既有量表的重编。

## 五、验证路线图（要达标需补齐的证据）

| 阶段 | 所需工作 | 大致样本量建议 | 产出 |
|---|---|---|---|
| ① 内容效度 | 专家评审题目代表性、措辞、覆盖面 | — | 内容效度报告 |
| ② 试测与项目分析 | 小样本施测，计算每题区分度、题—总相关 | 200–300 | 剔题/改题依据 |
| ③ 内部一致性 | 计算各维 α 与 α-if-item-deleted | 沿用 ② 样本 | α 系数表 |
| ④ 重测信度 | 间隔 2–4 周重测，算各维相关系数 | 100+ | 重测信度 |
| ⑤ 结构效度 | EFA 验证维度归属，CFA 验证 14 维模型 | 500–1000+ | 因子结构报告 |
| ⑥ 效标效度 | 与成熟量表（如对应构念）求相关 | 300+ | 效标效度报告 |
| ⑦ 常模建立 | 按性别/年龄等分组建常模 | 1000+ | 常模表 |

> 达到"可用作标准化测量工具"至少需要完成 ①–⑥；常模（⑦）使结果可作人群对照。此为开源项目，欢迎研究者或机构参与协同完成。

## 六、数据贡献通道（开放）

本项目开源且完全本地运行，**默认不收集任何作答数据**。若要推进上述验证，需在知情同意的前提下自愿参与数据贡献。可行的通道：

- **研究者 / 机构合作**：有施测条件的高校、研究机构、学校、企业可联系作者洽谈受控的匿名化施测与联合研究。
- **公开数据池（未来）**：在取得充分知情同意与伦理审批后，可考虑建立去标识化的开放数据池。
- **联系方式**：**programmingscience@foxmail.com**

在未建立受控施测与数据治理前，本项目不主动收集、上传任何个体作答数据，以保护隐私为最高优先。

## 七、结论

- **作为科学测量工具**：尚未达标，需按第五节路线图补齐实证证据。
- **作为开源自我探索工具**：合格——内容原创、结构清晰、计分自洽、体验规范，且有清晰的边界声明。

本文件与官网、答题页中的声明共同构成 LSM-140 的正式定位记录。

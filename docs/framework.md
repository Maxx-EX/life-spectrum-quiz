# 生命光谱模型（Life Spectrum Model, LSM-140）

> 原创心理测评框架 · 完全开源 · 可自由使用与二次开发
> 本模型及全部题目为原创内容，不复制、不改编自任何既有心理量表（如 SCL-90、MMPI、大五人格、MBTI 等），无版权争议。

---

## 一、框架理念

生命光谱模型把一个人的内在心理资源看作一道**光谱**——由 14 条彼此独立又相互影响的光带（维度）组成。
每一条光带代表一类心理运作能力，它们的**亮度组合**勾勒出个体独特的心理生态位。

与"贴标签型"测评不同，LSM-140 不做类型归类的武断判断，而是呈现一个**连续的光谱画像**：
你在哪些光带上更亮、哪些更暗、整体是否均衡，从而获得一幅"此刻的我"的结构化自画像。
它不是诊断工具，而是一面供自我观察与反思的镜子。

## 二、五大光谱域与 14 个维度

题目覆盖认知、情绪、关系三大心理运作域，另加贯穿性的**内在锚定域**与**性别光谱域**，共 5 域 14 维，每维 10 题，合计 **140 题**。

| 光谱域 | 维度 | 维度定义（原创构念） |
|---|---|---|
| 认知光谱 | 认知弹性 | 面对新信息与环境变化时，调整既有观点与行为策略的灵活程度——"松动而不失锚"。 |
| 认知光谱 | 专注锚定 | 在干扰环境下将注意力稳定附着于目标任务，并在分心后快速"回锚"的能力。 |
| 认知光谱 | 好奇探索 | 对未知与陌生事物内在兴趣的强度，以及主动接近不确定性的倾向。 |
| 认知光谱 | 决策权衡 | 决策时偏好审慎分析权衡，还是依赖直觉快速行动（高分=审慎型，低分=直觉型）。 |
| 情绪光谱 | 情绪复原 | 经历挫败、冲突或负性事件后，情绪强度回落至基线水平的速度与彻底性。 |
| 情绪光谱 | 压力代谢 | 对持续压力输入的"消化"效率——压力感知阈值与压力后的恢复资源。 |
| 情绪光谱 | 乐观基调 | 基于自我效能感的建设性未来预期，一种"有把握的乐观"底色。 |
| 情绪光谱 | 情绪觉知 | 对自身情绪的识别、命名与定位能力，是情绪调节的前提。 |
| 关系光谱 | 边界建构 | 在亲近与疏离之间建立清晰、灵活、可协商的人际界限的能力。 |
| 关系光谱 | 社交能量 | 人际互动中的能量收支：互动带来充盈还是耗竭，以及独处恢复的偏好。 |
| 关系光谱 | 共情通道 | 理解并感受他人立场与情绪的能力，涵盖情感共情与认知共情。 |
| 内在锚定域 | 独立自主 | 在决策与价值取向上不依赖外部确认、保持内在一致性的程度。 |
| 性别光谱域 | 工具效能 | 认知性别·工具性风格：目标导向、直接决断、依赖逻辑与行动（与生理性别无关）。 |
| 性别光谱域 | 表达温暖 | 认知性别·表达性风格：情感细腻、主动表达、共情与关系维系（与生理性别无关）。 |

> **关于性别光谱域**：它描述的是**认知性别**——一个人处理任务（工具效能）与经营关系（表达温暖）时的气质倾向，与生理性别、性取向无关。每个人身上都同时存在两种取向，即"心理双性化"。该域用于呈现你更惯用的认知风格，而非对你做性别归类。

## 三、计分方法（原始框架）

- 每题提供 4 个选项：`非常不符合 · 较不符合 · 较符合 · 非常符合`，对应分值 1–4。
- **反向题**（题目标注 `R`）：原始分按 `5 - 原始分` 反转，使"正向作答"在所有题上方向一致。
- 每个维度的**原始分** = 该维 10 题的（反转后）得分之和，范围 **10–40**。
- 将原始分映射为 **0–100 的标准化分**：
  `标准化分 = (原始分 - 10) / 30 × 100`，保留一位小数。
- **心理平衡指数（PBI）** = 14 个维度标准化分的算术平均，同样落在 0–100。
- **光谱一致性（SC）** = 14 个维度标准化分的标准差，衡量画像的"均衡程度"（越小越均衡）。

### 分数带（Bands）

| 区间 | 标签 | 含义 |
|---|---|---|
| 0–40 | 低亮 | 该光带相对较弱，可能是需要被关照或仍在成形的领域 |
| 41–70 | 中亮 | 处于普通常见范围，随情境波动 |
| 71–100 | 高亮 | 该光带较为充沛，是此刻的突出优势 |

> 提示：分数无"好坏"，只描述"位置"。高亮不等于完美，低亮也不等于缺陷——它们共同构成你的应对模式与潜能方向。

## 四、报告结构

1. **光谱图谱**：14 维度雷达图，一眼看到整体形态与均衡度。
2. **维度解读**：逐维给出基于分数带的个性化文字分析。
3. **光谱域总结**：认知 / 情绪 / 关系 / 内在锚定 / 性别光谱五域的汇总。
4. **认知性别画像**：基于工具效能与表达温暖两维，进行"心理双性化 / 工具导向 / 表达导向 / 探索型"四分类的深层评估。
5. **综合画像**：结合最高 3 项与最低 3 项维度，生成一段结构化自画像描述。
6. **平衡指数与建议**：PBI 与 SC 的解读，以及可执行的自我关照方向。

## 五、适用范围与边界（重要）

- 本测试**仅用于自我探索、教育与反思**，**不构成任何医疗诊断、精神健康评估或临床干预依据**。
- 若你正经历持续的强烈痛苦、失眠、情绪失控或影响生活的困扰，请务必寻求**专业心理师或精神科医生**的帮助。
- 题目作答反映的是"近期一惯状态"，会随生活阶段变化，建议间隔数月后重测以观察变化。

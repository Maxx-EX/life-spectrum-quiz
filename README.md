# 生命光谱心理测试 · 在线答题 LSM-140

> 一套**完全原创、开源免费**的心理测评在线答题页。140 道原创题，每题 4 个选项，作答后自动生成光谱图谱与深度分析。

**在线答题：https://lifelife.bbroot.com**

## ✨ 特性

- **100% 原创**：理论、题目、计分、解读全部原创，不复制任何既有量表，无版权争议。
- **每题 4 选项**：非常不符合 / 较不符合 / 较符合 / 非常符合，选项横向排在同一行。
- **140 题覆盖广**：认知（弹性/专注/好奇/决策）、情绪（复原/压力代谢/乐观/觉知）、关系（边界/社交能量/共情）、内在锚定（独立自主）、性别光谱（工具效能/表达温暖）。
- **一键深度分析**：作答后生成 ① 雷达光谱图谱 ② 逐维度解读 ③ 五大光谱域总结 ④ 认知性别画像（心理双性化/工具导向/表达导向/探索型四分类） ⑤ 综合画像 ⑥ 心理平衡指数（PBI）与光谱一致性（SC）。
- **隐私安全**：全部在本地浏览器计算，不收集、不上传任何数据。

## 🚀 本地运行

```bash
git clone <repo-url> psy-lifespectrum-quiz
cd psy-lifespectrum-quiz
python3 -m http.server 8000   # 或直接双击 index.html
```
